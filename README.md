#### Что делают предлагаемые хуки commit-msg и prepare-commit-msg?

Предлагаемые для установки хуки `commit-msg` и `prepare-commit-msg` делают в конечном итоге
одну и ту же работу: они формируют scope и footer в commit-сообщении (см. https://www.conventionalcommits.org/en/v1.0.0),
снабжая это сообщение вспомогательной информацией о месте, в котором были сделаны изменения,
и информацией о том, в рамках какой задачи эти изменения выполнены.

Хук находит общую часть в пути всех измененных в рамках коммита файлах, и на основании этой общей части
добавляет в scope сообщения "[DEV]:" или "[QA]:".
Если добавляется "[DEV]:", это означает, что измененные в рамках коммита файлы касаются кода разработки.
Если добавляется "[QA]:" - изменения сделаны в коде автотестов.
Данная информация позволит отличить в истории проекта коммиты команды разработки и команды тестирования.

Информация о задаче, в рамках которой появляются новые коммиты, берется из имени git-ветки, в которой работает
инженер. Предполагается, что в команде присутствует правило именования веток - имя ветки должно содержать JiraId задачи,
в рамках которой идет работа на этой ветке, далее из имени ветки хук берет JiraId и добавляет его в footer коммит сообщения.
Эта информация позволит, глядя на историю изменений в git, определить сущность в Jira, в рамках которой работал инженер.
Если ветка не содержит паттерн JiraId, footer не заполняется.

#### Как установить хуки?

1. Откройте терминал или [git bash](https://git-scm.com/install/windows).
2. Перейдите в корень проекта, который находится под управлением git и в который вы хотите добавить hook-и.
3. Если вы пользуетесь [Fork](https://git-fork.com/), установите хук `commit-msg`, выполняя следующие команды последовательно:

```bash
git clone --depth 1 https://gitverse.ru/PavelLiulchak/githooks.git /tmp/hooks
cp /tmp/hooks/commit-msg .git/hooks/
cp /tmp/hooks/hooks-helper-functions.sh .git/hooks/
chmod +x .git/hooks/commit-msg
rm -rf /tmp/hooks
```

3*. Если вы работаете с git-ом через терминал без использования GUI-инструментов, можете установить 
хук `commit-msg` (см. предыдущий шаг) или `prepare-commit-msg`:
```bash
git clone --depth 1 https://gitverse.ru/PavelLiulchak/githooks.git /tmp/hooks
cp /tmp/hooks/prepare-commit-msg .git/hooks/
cp /tmp/hooks/hooks-helper-functions.sh .git/hooks/
chmod +x .git/hooks/prepare-commit-msg
rm -rf /tmp/hooks
```
4. Откройте установленный вами хук и присвойте в нем следующим переменным значения релевантные вашему проекту:
DEV_DIR=<директория с кодом разработки>
QA_DIR=<директория с кодом автотестов>
JIRA_PROJECT_KEY=<ключ сущностей в Jira>

Замечание: на данный момент хуки обрабатывают ситуацию, когда QA_DIR - поддиректория DEV_DIR.

Замечание: помните, что хук `prepare-commit-msg` срабатывает до того, как вы напишете описание (description)
и тело (body) вашего коммит сообщения, а `commit-msg` отработает после, выбирайте один подходящий для вас
способ.

#### Требования
Требуется bash версии >= 4.3
